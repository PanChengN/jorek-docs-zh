# 翻译作业书（所有译者必读，逐条执行）

你在为 **JOREK 中文文档站** 翻译页面。本站是 JOREK 官方 Wiki 的逐页中文镜像：**版式、目录结构、导航层级与英文原站完全一致，只把语言换成中文。**

## 路径约定

- 项目根：`<项目根，即本仓库根目录>`
- 英文原文：`<英文原文目录：上游仓库的 docs/ 目录>/<相对路径>`
- 目标文件：`<项目根，即本仓库根目录>/<相对路径>`（**已存在**，与源同名同路径）
- 任务里给出的页面清单，路径一律是**相对项目根**的路径

## 铁律

1. **只改正文。** front matter（两行 `---` 之间）**逐字保留**：`title` / `parent` / `grand_parent` 已是中文，`nav_order`、`has_children`、`layout`、`render_with_liquid` 等全部不得改动、不得增删、不得重排。front matter 之后与正文之间的空行保留一行。

2. **删掉未翻译提示块**（不删会被判为未翻译）：

   ```html
   <!-- untranslated-notice -->
   <div class="warning" markdown="1">
   **本页尚未翻译**……
   </div>
   ```

3. **术语照 [`i18n/glossary.md`](glossary.md) 写**，不要自创译法。首次出现的缩写写"中文全称（缩写）"，其后直接用缩写。

4. **绝对不翻译**：命令行、shell 脚本、`Makefile.inc` 内容、编译器/链接器标志、namelist 参数名（`tstep`、`eta`、`F0`…）、函数名、模块名、文件路径、目录名、URL、库名（SCOTCH/PaStiX/MUMPS/MKL/FFTW…）、装置名（ITER/JET/ASDEX Upgrade…）、软件名（ParaView/VisIt…）。代码块内部一个字符都不改，包括注释。

5. **数学公式逐字符保留**：`$$…$$`、`\(…\)`、`\begin{align*}…\end{align*}` 内的符号、下标、`\\` 换行、`\text{}` 一律不动。只翻译公式外的文字。

6. **逐段对应**：原文一段 → 译文一段。不合并、不拆分、不省略、不添加原文没有的内容。原文的列表项数、表格行数与列数、标题层级、链接数量必须与原文一致。

7. **结构语法保持**：kramdown 的 `{: .note }` / `{: .warning }`、属性列表 `{:.align-center}`、引用式图片 `![alt][ref]` 及其定义、HTML 标签、`<img>` 的 src 与 width，全部保留。链接的相对路径不改，**只译链接文字**。

8. **原文有错照译，不擅自修正。** 确认为明显笔误时，可在该处加一条 `{: .warning }` 译者注说明，每页最多一处。

9. **不动上游目录**（上游文档副本目录）里的任何文件，不碰清单之外的任何文件，不执行 git 操作。

10. 若某页原文正文本来就是空的（只有 front matter，或只有一行 `*This page is a stub — content to be added.*`）：前者译文正文保持为空，后者照译成"本页为占位页——内容待补充。"，**不要凭空编造内容**。

## 交付前自检（必须真实执行，不许口述）

```bash
cd <项目根，即本仓库根目录>
UP="${JOREK_DOCS_DIR:-../upstream/docs}"

# 1) 提示块应全部清除（无输出为通过）
grep -rl 'untranslated-notice' <你的页面清单>

# 2) 结构指纹逐页对比：代码块 / 公式 / 标题 / 链接 / 表格 / 列表
for f in <你的页面清单>; do
  printf "%-60s fence %s/%s  \$\$ %s/%s  h %s/%s  link %s/%s\n" "$f" \
    $(grep -c '^```' "$f") $(grep -c '^```' "$UP/$f") \
    $(grep -c '\$\$' "$f") $(grep -c '\$\$' "$UP/$f") \
    $(grep -c '^#' "$f") $(grep -c '^#' "$UP/$f") \
    $(grep -o '](' "$f" | wc -l) $(grep -o '](' "$UP/$f" | wc -l)
done
```

任何一项不一致都要回头修，不能"差不多"就交。
